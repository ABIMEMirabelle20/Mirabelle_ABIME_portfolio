# Portfolio de Mirabelle ABIME

React 19, Vite, Three.js (react-three-fiber), framer-motion. Français et anglais.

```bash
npm install
npm run dev       # développement
npm run build     # production
npm run preview   # tester le build
```

Avant une mise en ligne, suis `DEPLOY_CHECKLIST.md`.

## Où modifier quoi

- Textes (FR/EN) : `src/i18n/translations.js`
- Projets : `src/data/projects.js` (images WebP dans `src/assets/projects/`)
- Couleurs, polices, espacements : `src/styles/variables.css`
- Formulaire de contact : `src/components/Contact.jsx` (Formspree)
